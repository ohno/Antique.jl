# Rigid Rotor

The linear rigid rotor model can be used in quantum mechanics to predict the rotational energy of a diatomic molecule. The rotational energy depends on the moment of inertia for the system, $I$.

## Definitions

```@docs; canonical=false
Antique.RigidRotor
```


## Usage & Examples

[Install Antique.jl](@ref Install) for the first use and run `using Antique` before each use. The energy `energy()`, wave function `wavefunction()` and potential `potential()` will be exported. In this system, the model is generated by `RigidRotor` and several parameters `m_1`, `m_2`, `R` and `hbar` are set as optional arguments.

```@example RR
using Antique
RR = RigidRotor(m_1=1.0, m_2=1.0, R=1.0, hbar=1.0)
; #hide
```

Parameters:

```@repl RR
RR.m_1
RR.m_2
RR.R
RR.hbar
```

Eigenvalues:

```@repl RR
energy(RR, l=0)
energy(RR, l=1)
energy(RR, l=2)
```

Wave functions:

```@repl RR
wavefunction(RR, 0, 0, l=2, m=1)
wavefunction(RR, π/4, 0, l=2, m=1)
wavefunction(RR, π/4, π/2, l=2, m=1)
```
