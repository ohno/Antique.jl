# Spherical Oscillator

The spherical oscillator (3D isotropic harmonic oscillator) is the most frequently used model in quantum physics. This model uses a spherical coordinate system.

## Usage & Examples

[Install Antique.jl](@ref Install) for the first use and run `using Antique` before each use. The energy `energy()`, wave function `wavefunction()` and potential `potential()` will be exported. In this system, the model is generated by `SphericalOscillator` and several parameters `k`, `mu` and `hbar` are set as optional arguments.

```@example SO
using Antique
SO = SphericalOscillator(k=1.0, mu=1.0, hbar=1.0)
; # hide
```

Parameters:

```@repl SO

Eigenvalues:

```
