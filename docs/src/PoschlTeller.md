# Pöschl-Teller Potential

The Pöschl-Teller potential is one of the few potentials for which the quantum mechanical Schrödinger equation has an analytical solution. It has a finite number of bound states, which can be inferred easily from its potential strength parameter lambda. It is defined for one-dimensional systems.

## Usage & Examples

[Install Antique.jl](@ref Install) for the first use and run `using Antique` before each use. The energy `energy()`, wave function `wavefunction()`, potential `potential()` and `n_max()` will be exported. In this system, the model is generated by `PoschlTeller` and the parameters `lambda`, `m`, `hbar`, `x_0`.

```@example PT
using Antique
PT = PoschlTeller(lambda=4, m=1.0, hbar=1.0, x_0=1.0)
; # hide
```

Parameters:


```@example PT
f = Figure()
```

Wave functions:

```@example PT
using CairoMakie

# setting
f = Figure()
ax = Axis(f[1,1], xlabel=L"$x$", ylabel=L"$\psi(x)$")

# plot
w0 = lines!(ax, -3..3, x -> wavefunction(PT, x, n=0))
w1 = lines!(ax, -3..3, x -> wavefunction(PT, x, n=1))
w2 = lines!(ax, -3..3, x -> wavefunction(PT, x, n=2))
w3 = lines!(ax, -3..3, x -> wavefunction(PT, x, n=3))

# legend
axislegend(ax, [w0, w1, w2, w3], [L"n=0", L"n=1", L"n=2", L"n=3"], position=:lb)

f
```

Potential energy curve, Energy levels, Wave functions:

```@example PT
using CairoMakie

# settings
f = Figure()
ax = Axis(f[1,1], xlabel=L"$x$", ylabel=L"$V(x),~E_n,~\psi_n(x) \times 5 + E_n$", aspect=1, limits=(-4,4,-10.5,1))
# hidespines!(ax)
# hidedecorations!(ax)

for n in 0:3
  # classical turning point
  xE = acosh(sqrt(PT.lambda*(PT.lambda+1)/abs(energy(PT,n=n))/2))
  # energy
  hlines!(ax, energy(PT, n=n), color=:black, linewidth=1, linestyle=:dash)
  lines!(ax, [-xE,xE], fill(energy(PT,n=n),2), color=:black, linewidth=2)
  # wave function
  lines!(ax, -4..4, x -> energy(PT,n=n) + wavefunction(PT,x,n=n), linewidth=2)
end

#potential
lines!(ax, -4..4, x -> potential(PT,x), color=:black, linewidth=2)

f
save("assets/fig/PoschlTeller.png", f) # hide
; # hide
```
